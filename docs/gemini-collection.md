# Gemini collection

The Gemini set adds a second complete collection of eight art styles, each with day and night ambient light. These are new compositions made in Gemini's signed-in web Images interface from the user's Home2.png reference, using native Chrome computer use. All masters are saved exactly as downloaded. The Original set remains separate and unchanged.

Nighttime defaults have dark surrounding backgrounds. The Ghibli night version was revised to remove its pale backdrop; synthwave daylight was revised to preserve the neon/chrome/grid treatment. Papercut was pushed toward simplified construction-paper forms. Earlier drafts remain selectable through the Version control, with their own room geometry, 32 light states, favorites and exports.

Each downloaded master has a separately generated all-artificial-lights-off reference and a visual registration of its five room regions. Room positions and bit order remain living room, kitchen, bedroom, hallway, study. The renderer samples only the reference's broad illumination field, resizing that field to the master's native dimensions when necessary. It keeps the downloaded master's objects, texture, lines and exterior pixels fixed. It rejects references with a materially different aspect ratio.

The app generates every combination locally and exports full-resolution PNGs or a ZIP of all 32 states. This is simulated artwork lighting; the open-plan living/kitchen boundary is intentional. Different generated artworks may vary in illustrated detail. Favorites store exact artwork IDs and room states in this browser, including separate draft identities. Source files and prompts contain no browser-session credentials.
